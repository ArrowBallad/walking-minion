# GI Demo 002 独立临床参考（仅供评估者）

> 本文件不得载入 Agent 的病例目录、提示、数据库、工具结果或患者记忆。

## 三层真相

### Underlying case truth

这名完全虚构的年轻男性患嗜酸性粒细胞性食管炎，具有季节性过敏性鼻炎的特应性背景。疾病表现为逐渐加重的固体食物吞咽困难和一次未完全嵌塞的鸡肉停顿。高剂量 PPI 治疗有效，使临床、内镜和组织学均明显改善。

### Documented truth

- 既往有过敏性鼻炎（gi-demo-002-rec-001）。
- 八个月固体食物吞咽困难，液体正常，无体重下降；低剂量 PPI 仅改善烧灼感，吞咽困难持续（rec-002 至 rec-004）。
- 胃镜实际完成并按近端、远端各三块取样（rec-007, rec-008）。
- 初次内镜 EREFS 为 E1/R1/Ex0/F1/S0，无需扩张的固定狭窄（rec-009）。
- 远端 48、近端 32 eos/hpf，并见相关反应性改变（rec-010）。
- 临床在综合症状、内镜、病理和替代原因后才确诊并选择高剂量 PPI（rec-011, rec-012）。
- 十二周时症状消失；复查内镜改善，病理降至远端 5、近端 3 eos/hpf（rec-013 至 rec-017）。
- 后续采用每日一次 PPI 维持，长期复查间隔尚未最终确定（rec-018）。

### Acceptable Agent conclusions

- 证据充分支持嗜酸性粒细胞性食管炎，而不仅是普通胃食管反流病。
- 高剂量 PPI 已获得症状、内镜和组织学反应；可称组织学缓解/反应，但不能称永久治愈。
- 初次操作记录、内镜外观和病理结果属于不同证据；症状改善本身不能代替复查活检。
- 可合理建议继续有效的维持治疗、复发安全教育，并在后续共同决定监测间隔。

## 仍待随访

- 降为每日一次 PPI 后能否维持临床和组织学缓解？
- 长期复查胃镜/活检的具体间隔尚未记录。
- 若再次出现食物嵌塞或固定狭窄，是否需要扩张和/或调整抗炎治疗。

## 不受支持的结论

- 仅以烧灼感诊断普通反流并忽略分层活检。
- 声称发生过需要急诊取出的完全食物嵌塞。
- 声称初次内镜存在固定狭窄或已实施扩张。
- 以症状消失直接证明组织学缓解；真正的复查病理证据来自 rec-017。
- 声称疾病已经治愈、可以停止全部治疗，或已经确定长期复查日期。
