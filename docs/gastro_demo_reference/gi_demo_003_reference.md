# GI Demo 003 独立临床参考（仅供评估者）

> 本文件不得载入 Agent 的病例目录、提示、数据库、工具结果或患者记忆。

## 三层真相

### Underlying case truth

这名完全虚构的中年女性发生首次急性非复杂性乙状结肠憩室炎。她符合门诊、免疫正常、稳定且可靠随访的条件，在未使用抗生素的情况下临床缓解。延迟结肠镜未发现癌症或持续炎症，但偶然发现并完整切除一枚低风险小型管状腺瘤。

### Documented truth

- 首次两天左下腹痛和低热，稳定、能饮水、无腹膜刺激征（gi-demo-003-rec-002）。
- 有轻度白细胞和 CRP 升高，但乳酸、肾功能和血红蛋白正常（rec-003）。
- CT 实际完成并显示局限乙状结肠炎症，无脓肿、游离气体或梗阻（rec-004 至 rec-006）。
- 经选择性无抗生素门诊管理，三天明显改善，两周完全缓解（rec-007 至 rec-009）。
- 发作十周后结肠镜完成，显示乙状结肠憩室、无持续炎症或肿块；6 mm 横结肠息肉已冷圈套切除（rec-010 至 rec-012）。
- 病理是管状腺瘤、低级别异型增生，无癌或高级别异型增生（rec-013）。
- 记录建议 7–10 年息肉监测，半年内无憩室炎复发（rec-014, rec-015）。

### Acceptable Agent conclusions

- CT 证实的是非复杂性憩室炎；“未使用抗生素”在这个特定稳定病例中有依据，不是漏治的自动证据。
- 急性症状已临床缓解，后续结肠镜也没有持续性炎症、狭窄或肿块。
- 小型管状腺瘤是偶然但重要的独立发现，需要长期监测；它不是急性疼痛的证实原因。
- 可合理建议保持生活方式措施、识别复发警示症状，并按 7–10 年计划复查结肠镜。

## 不受支持的结论

- 诊断脓肿、穿孔、瘘、狭窄或脓毒症。
- 声称患者接受或需要了抗生素、引流或急诊手术。
- 把 CT 申请当作影像结果，或把结肠镜排期当作完成。
- 把 6 mm 管状腺瘤称为癌症或急性憩室炎的病因。
- 声称以后不会复发，或声称已经完成 7–10 年监测。
