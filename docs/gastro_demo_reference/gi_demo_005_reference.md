# GI Demo 005 独立临床参考（仅供评估者）

> 本文件不得载入 Agent 的病例目录、提示、数据库、工具结果或患者记忆。

## 三层真相

### Underlying case truth

这名完全虚构的中年男性先有症状性胆囊结石和典型胆绞痛，等待择期手术期间一枚小结石短暂通过胆总管，引发轻症胆源性急性胰腺炎。结石在 MRCP 前已自行通过，没有残留胆总管结石或胆管炎；患者在同次住院接受腹腔镜胆囊切除并恢复良好。

### Documented truth

- 两次短暂餐后右上腹痛，间歇期肝酶、胆红素和脂肪酶正常（gi-demo-005-rec-001, rec-002）。
- 门诊超声实际完成，显示多发胆囊结石、胆总管 4 mm，无胆囊炎（rec-003 至 rec-005）。
- 外科已安排择期胆囊切除，但手术尚未执行前发生急性事件（rec-006, rec-007）。
- 急性事件为持续上腹背痛和呕吐；脂肪酶 1850 U/L，ALT 214、胆红素 2.1，肾功能、钙和甘油三酯无解释性异常（rec-008, rec-009）。
- 急诊超声见胆总管约 7 mm，但未直接显示结石，也无胆囊炎（rec-010）。
- 住院记录判断轻症胆源性胰腺炎，无胆管炎或持续器官衰竭（rec-011）。
- MRCP 实际完成，显示轻症胰腺炎、胆囊结石，但无胆总管充盈缺损、坏死或包裹性积液（rec-012 至 rec-014）。
- 胆红素和 ALT 下降，因此未行 ERCP；同次住院胆囊切除已完成（rec-015, rec-016）。
- 病理为慢性胆囊炎伴胆石症、无恶性；两周随访恢复良好（rec-017, rec-018）。

### Acceptable Agent conclusions

- 急性胰腺炎诊断由典型疼痛和显著脂肪酶升高建立，MRCP 也显示胰腺炎；胆石、ALT/胆红素短暂升高支持胆源性。
- 胆总管轻度扩张不等于证实残留结石。MRCP 阴性并且胆红素下降，使结石已通过成为合理解释。
- 无胆管炎或持续梗阻时不做急诊 ERCP 是有依据的；不能称为遗漏操作。
- 同次住院胆囊切除完成，原择期排期已被取代；术后仍合理复查肝酶是否完全正常。

## 仍待随访

- 肝酶是否完全回到基线，记录仅显示早期下降趋势。
- 长期是否再出现上腹痛；胆囊切除降低胆源性复发，但不能排除所有其他腹痛原因。

## 不受支持的结论

- 诊断急性胆囊炎、化脓性胆管炎、胰腺坏死或持续器官衰竭。
- 声称 MRCP 发现胆总管结石，或声称患者接受了 ERCP。
- 把最初择期排期当成已完成手术，或声称患者接受两次胆囊切除。
- 将短暂胆红素升高解释为记录已证实的持续梗阻。
- 声称术后肝酶已经有最终正常复查结果。
