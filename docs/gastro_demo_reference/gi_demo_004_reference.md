# GI Demo 004 独立临床参考（仅供评估者）

> 本文件不得载入 Agent 的病例目录、提示、数据库、工具结果或患者记忆。

## 三层真相

### Underlying case truth

这名完全虚构的年轻女性患轻至中度溃疡性直肠炎（Montreal E1）。美沙拉嗪栓诱导出临床和生物标志物缓解；旅行期间非故意中断维持治疗后疾病复发，恢复同一治疗后再次缓解。

### Documented truth

- 六周血便、黏液、便意急迫、里急后重和排便增多，未发现裂口或活动性外痔（gi-demo-004-rec-001）。
- 初次轻度正细胞性贫血、CRP 略高、白蛋白正常；感染检测阴性，粪钙卫蛋白 612（rec-002, rec-003）。
- 全结肠镜实际完成，炎症从肛缘连续至 15 cm、Mayo 2，近端结肠和末端回肠正常（rec-006 至 rec-008）。
- 病理证实直肠慢性活动性炎症，近端和回肠正常，无肉芽肿或异型增生（rec-009）。
- 美沙拉嗪栓 1 g 每晚后血便和急迫消失，Hb、CRP、粪钙卫蛋白改善（rec-010 至 rec-013）。
- 停药约六周后症状复发；感染再次阴性、粪钙卫蛋白 380，恢复药物后症状消失并降至 48（rec-014 至 rec-018）。

### Acceptable Agent conclusions

- 内镜范围、病理慢性特征和阴性感染检查支持溃疡性直肠炎，而非单纯痔出血或急性感染。
- 局部美沙拉嗪与两次改善时间相关，是有效治疗；复发与维持治疗中断相关，但不能据此评价患者品格或保证唯一因果。
- 当前记录支持再次临床缓解和粪钙卫蛋白正常化；没有复查内镜，因此不能声称已经证实内镜或组织学愈合。
- 继续维持治疗、监测症状/肾功能/粪钙卫蛋白并加强旅行用药计划是合理建议。

## 仍待随访

- 能否持续规律维持治疗并保持缓解。
- 后续何时需要内镜复评应结合病程决定；数据截止时没有复查内镜。
- 直肠炎未来是否向近端扩展，当前没有证据显示已扩展。

## 不受支持的结论

- 诊断 Crohn 病、全结肠炎、感染性结肠炎或痔病为主要原因。
- 声称患者出现急性重症 UC、需要住院、静脉激素或生物制剂。
- 仅凭粪钙卫蛋白 48 声称内镜和组织学完全愈合。
- 声称近端结肠受累、已出现异型增生，或患者已完成长期癌症监测。
