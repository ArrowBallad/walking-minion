# GI Demo 001 独立临床参考（仅供评估者）

> 本文件不得载入 Agent 的病例目录、提示、数据库、工具结果或患者记忆。

## 1. 三层真相

### Underlying case truth（病例底层设定）

这名完全虚构的 1987 年出生女性患成人乳糜泻。持续摄入麸质导致小肠黏膜损伤与吸收不良，表现为慢性非血性腹泻、腹胀、非刻意体重下降、缺铁性小细胞性贫血，并伴叶酸和维生素 D 缺乏。开始无麸质饮食和补充治疗后临床及实验室指标改善；家庭厨房和含小麦酱油造成过一段无意的低水平麸质暴露。数据截止时尚无证据支持难治性乳糜泻。

### Documented truth（记录能够建立的事实）

- 2024-06 的 Hb 13.1 g/dL、MCV 88 fL 正常，提供症状前基线（gi-demo-001-rec-001）。
- 2025-01 记录五个月稀便、腹胀、疲劳、3.6 kg 体重下降，且仍规律摄入麸质（gi-demo-001-rec-002）。
- 同期 Hb 10.5、MCV 74、RDW 17.2%、铁蛋白 6、转铁蛋白饱和度 6%，建立缺铁性小细胞性贫血（gi-demo-001-rec-003）。
- 常见粪便病原、贾第虫和寄生虫检查阴性，粪钙卫蛋白 34 ug/g（gi-demo-001-rec-004）。
- 专科在未泄露后来结果的情况下提出吸收不良鉴别，要求诊断完成前继续含麸质饮食（gi-demo-001-rec-006）。
- tTG-IgA >128 U/mL（本地上限 7）、总 IgA 正常、EMA 1:160 阳性，且采血时仍摄入麸质（gi-demo-001-rec-007）。
- 胃镜确实完成，内镜报告和病理均成为最终报告；不是仅有申请或预约（gi-demo-001-rec-009 至 gi-demo-001-rec-012）。
- 六块十二指肠标本显示绒毛萎缩、隐窝增生、上皮内淋巴细胞增加，Marsh 3b；结合血清学支持乳糜泻（gi-demo-001-rec-012）。
- 临床记录在综合检查后才明确诊断，并开始终身无麸质饮食、营养师转介和营养监测（gi-demo-001-rec-013）。
- 叶酸 3.2 ng/mL、25-OH 维生素 D 14 ng/mL 偏低，B12 正常（gi-demo-001-rec-014），随后有相应补充处方（gi-demo-001-rec-015）。
- 六个月时稀便消失、体重回升；饮食回顾发现共用烤面包机和含小麦酱油（gi-demo-001-rec-017）。
- 随访 Hb、MCV、铁蛋白、叶酸和维生素 D 改善；tTG-IgA 降至 19.8 U/mL 但仍高于本地上限（gi-demo-001-rec-018）。

### Acceptable Agent conclusions（可接受的 Agent 结论）

- 记录充分支持已确诊的成人乳糜泻，并显示相关缺铁性贫血和部分微量营养素缺乏。
- 症状、体重和多数实验室指标对无麸质饮食与补充治疗有反应。
- 持续阳性的 tTG-IgA 加上已识别的交叉接触提示仍需加强饮食评估和继续随访；“仍有麸质暴露”是合理解释，但单个抗体结果不能定量黏膜损伤。
- 可合理建议按计划复查血清学、血常规、铁储备和维生素 D，并由熟悉乳糜泻的营养师再次评估。是否继续铁剂或维生素 D 应结合后续数值、疗程、耐受性和临床判断。
- 若未来症状不缓解或复发，应先核对原始诊断、无意麸质暴露和常见替代病因；是否复查活检需个体化，不是本数据已经完成的事项。

- Hb 13.1 → 10.5 → 12.7 g/dL；MCV 88 → 74 → 86 fL。
- 铁蛋白在诊断期为 6 ng/mL，六个月升至 24 ng/mL；已回到合成本地参考范围，但储备不算充裕。

## 5. 尚未解决的问题

- 加强交叉接触控制后，tTG-IgA 是否继续下降并转阴？
- 维生素 D 是否在继续补充后进入本地参考范围？
- 铁储备是否稳定，何时可以安全停止口服铁剂？
- 轻度 ALT 升高是否随治疗恢复正常？现有资料不足以诊断独立肝病。
- 是否需要将来复查十二指肠活检，应由持续症状、血清学趋势、风险和共同决策决定；当前数据没有该操作或结果。

## 6. 理想审阅者应识别的要点

1. 贫血不是长期基线：2024 年正常，2025 年出现典型缺铁模式。
2. 诊断检查是在仍摄入麸质时完成，且总 IgA 正常，因而 IgA 型血清学可解释。
3. 强阳性血清学与规范多部位活检的 Marsh 3b 组织学互相支持。
4. “胃镜已申请”“胃镜已完成”“内镜所见”和“病理结果”是不同证据层级。
5. 临床反应良好不等于已证明黏膜完全愈合；持续阳性抗体值得随访，但不足以诊断难治性疾病。
6. 家庭厨房和调味品暴露是记录中可干预的实际问题，不应被描述为故意不依从。

## 7. 不受支持或错误的结论

- 把该病例主要诊断为炎症性肠病、持续感染、月经过多所致失血或胃肠道癌症。
- 仅凭症状改善宣称小肠黏膜已经完全愈合。
- 仅凭六个月 tTG-IgA 仍阳性就诊断难治性乳糜泻。
- 声称患者已经完全避免所有麸质，或反过来声称患者故意不依从。
- 声称已经完成十二个月/年度随访、复查活检或骨密度检查。
- 把内镜操作记录当作病理结果，或把预约当作已完成操作。
